Как создать ярлык Для этого файла

Браузеры не дают создавать ярлыки для локальных файлов. Чтобы вынести сканер на рабочий стол:

Android:
  • Откройте приложение «Проводник» (или «Файлы») на телефоне.
  • Найдите этот скачанный файл.
  • Зажмите его пальцем и выберите «Создать ярлык» (или «Добавить на рабочий стол»).
iPhone:
  • Локальные файлы нельзя вынести на рабочий стол.
  • Сохраните файл в приложении «Файлы» для быстрого доступа.
ПК:
  • Нажмите правой кнопкой мыши на файл -> «Отправить» -> «Рабочий стол (создать ярлык)».

Совет: Если вам нужна красивая иконка приложения, лучше установите основную версию сайта (кнопка «Установить» на главной).
